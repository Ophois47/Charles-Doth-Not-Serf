# Charles Doth Not Serf

Charles Doth Not Serf is one of my earliest substantial programming projects, developed in Unity and C# in 2019 while I was teaching myself software development.

The game included enemy and boss behavior, combat, quests and objectives, NPC interactions, inventory, character progression, cutscenes, menus, and scene transitions. This repository preserves the original gameplay source largely as it was written at the time rather than rewriting it to reflect my current programming practices.

## Historical Context

I began learning software development in February 2019. Charles Doth Not Serf was developed during that first year and was one of the projects I used to learn C#, object-oriented programming, Unity's component model, game-state management, physics, animation, coroutines, and gameplay programming.

I entered professional software engineering in October 2019 and continued independent development in C, C++, Python, Go, Rust, machine learning, emulation, systems programming, and cross-platform software.

## Repository Contents

This repository contains the original C# gameplay source, including code for:

- Enemy and boss behavior
- Combat and damage
- Quests and objectives
- NPC interaction
- Inventory
- Health, experience, levels, and currency
- Cutscenes
- Menus
- Scene transitions

The original Unity project also contained several gigabytes of models, textures, audio, third-party Unity packages, generated data, and compiled builds. Those files are intentionally excluded. This repository is preserved as a source-code archive of the programming work.
